# Arden Olgundemir — İlk Görev Kartı

**Pod:** Keşif ve Vaka Açma  
**Rol:** Lead / Contract  
**Şu an:** `CASE-CONTRACT-01` Owner

## Şimdi ne yapacaksın?

Yönlendirmeli vaka formunun uygulanabilir contractını çıkaracaksın. Alp bu contracta bakıp formu kodlayabilmeli; Burak her kural için test yazabilmeli.

## Teslimin

- alanlar ve validation tablosu;
- form durumları;
- UI input/output type taslağı;
- non-goal listesi;
- build dosya sınırı;
- normal + invalid acceptance kriterleri;
- açık blocker/kararlar.

Detaylı task: [Pod 1 — CASE-CONTRACT-01](../03-POD-1-KEŞİF-VE-VAKA-AÇMA.md#case-contract-01--vaka-formu-contractı)

## Sıra

1. Taskı `In Progress` yap.
2. Önce ürün kurallarını ve repo patternlerini incele; kod yazma.
3. Contract taslağını taska koy.
4. Alp'ten uygulanabilirlik review'u, Burak'tan test edilebilirlik kontrolü al.
5. Açık kararları çöz; contractı `Done` yap.
6. `CASE-BUILD-01` açılınca reviewer ol.

Bu taskta auth, API, DB veya production kodu yazmıyorsun.
